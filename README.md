## ⚙️ Prerequisites

Before you begin, ensure you have the following installed:

- **Node.js** (v18.x or higher recommended) – [Download](https://nodejs.org/)
- **npm**
- **Git** – [Download](https://git-scm.com/)

Optional:

- **VS Code** (recommended IDE) – [Download](https://code.visualstudio.com/)
- **Docker** (for containerized setup) – [Download](https://www.docker.com/)

## 📦 Dependencies

Core dependencies used in this project:

| Package         | Purpose                                   |
|----------------|-------------------------------------------|
| next           | React framework for production            |
| react          | UI library                                |
| react-dom      | DOM-specific methods for React            |
| tailwindcss    | Utility-first CSS framework (optional)    |
| axios          | Promise-based HTTP client (optional)      |
| dotenv         | Environment variable loader               |
| eslint         | Linting utility                           |
| prettier       | Code formatter                            |

Dev dependencies (examples):

- `eslint-config-next`
- `autoprefixer`
- `postcss`

## 🚀 Installation

# Clone the project
git clone https://github.com/sinjan08/kurixel.git

# Navigate to project directory
cd kurixel

# Install dependencies
npm install

---

## 💻 Running the App

# Start development server
npm run dev

---

## 📦 Build for Production

# Build the app
npm run build

# Start the production server
npm start
